## 八场景分类基线

完整数字见 JSON 的 `八场景基线`。要点：

模型判定与校准后估计两个口径都要给，因为分类器召回普遍低于精确率，会往「其他」漏。macro F1 66.1%，纯随机检验集（n=386）一致率 79.3%。判例检索、药品与器械查询标注量小，精确率区间 ±19 和 ±10，只能当存在性证据。「人工标注」实为 LLM 盲标，是该口径下的上限估计。

目标源自然出现率：合规与法规检索 0.4%、判例检索 2.4%、公司与行业分析 4.0%、循证医学问答 6.5%、药品与器械查询 7.6%、实时与地域信息 11.3%、文献综述 43.3%、西葡语学术研究 45.4%。前四个是纯增量缺口。
